# LinkedIn Profile Review

Use this file after you have retrieved a LinkedIn profile and need to evaluate what it means for the decision.

## What to evaluate

Evaluate LinkedIn evidence against the three core questions:

1. **Role fit**: Does the profile show work that matches the posted job opening?
2. **Evidence quality**: Is the profile specific enough to support a confident decision?
3. **Follow-up need**: Is there a concrete missing detail that should trigger follow-up instead of an immediate decision?

## Positive signals

- Current or recent roles align with the job opening being screened for.
- Experience history shows sustained relevant work, not a one-off adjacent project.
- Profile descriptions mention responsibilities, systems, or outcomes that map to the job description.
- Education, talks, publications, portfolio, or certifications reinforce fit when available.
- Location, naming, and profile details are coherent with the application data.

## Negative signals

- Current/recent roles appear unrelated to the job opening.
- Experience indicates only occasional or shallow adjacency to the required work.
- Profile appears sparse/incomplete with little evidence of real professional depth.
- Material inconsistencies across name, location, role, dates, or claimed expertise.
- Indicators of misrepresentation or a clearly different person/profile context.

## How to use LinkedIn evidence in decisions

- Strong profile alignment can justify `recommend_advance` when it clearly maps to the job opening.
- Weak or conflicting profile evidence should usually move to `recommend_follow_up` unless disqualifying evidence is clear.
- If profile evidence clearly shows a mismatch with the opening, `recommend_decline` can be appropriate.
- If LinkedIn evidence materially informed the recommendation, inline the exact LinkedIn URL in checklist lines and in `Rationale` so reviewers can see how it was used.

## If LinkedIn retrieval fails

- Retrieval failure is not positive evidence and should not be used to justify advancement.
- If role fit is still not sufficiently proven after LinkedIn failure, prefer `recommend_follow_up` unless there is already clear disqualifying evidence.
- Advance without LinkedIn only when equivalent alternate evidence is strong enough (for example portfolio, talks, GitHub, company/team pages, or prior validated context).
- If alternate evidence is weak, conflicting, or incomplete, do not advance.

## Correspondence implications

When LinkedIn evidence is incomplete or conflicting, request one or two precise clarifying items (for example a portfolio link, a specific project example, a case study, GitHub, or an updated profile) rather than a broad questionnaire.
