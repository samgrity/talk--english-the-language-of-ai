Where the agent gets smart

The skill file
is where the workflow lives.

These days it’s often enough to implement the workstream in English: what to look at, what order to do it in, how to judge the result, and what output shape is allowed.

# Screen Candidate ## Screening flow 1. Read candidate details ... 2. Read prior updates ... 3. Read the job description carefully ... 4. Run a quick email-risk pass ... 5. Obtain the candidate's full LinkedIn profile ... ...
SteerabilityOrdered steps№14 / 18
Why the screening flow matters

If you’re implementing a workflow, defined steps are a big deal.

  1. read candidate + job details
  2. read prior updates
  3. read job description carefully
  4. run quick email-risk pass
  5. obtain full LinkedIn profile
  6. evaluate role fit

Defined steps make the agent easier to follow.

They also make debugging dramatically easier.

Instead of “the agent went weird,” you can say: we were in step four and that judgment went off course.

Structured artifactsInternal notes№16 / 18
Another subtle move

Even the internal notes
are a contract.

[✓] Role fit: ... [✓] Evidence quality: ... [✓] Job-opening alignment: ... [ ] LinkedIn profile: ... [✓] Email risk check: ... [ ] Missing evidence: ... Recommendation: recommend_follow_up Rationale: ...
This is not just “nice formatting.” It narrows the space of possible bad outputs, makes reviews scannable, and gives you better failure modes.
